# ScoreNote · 成绩手记

使用 Flutter 制作的高中成绩记录工具。

## 试用流程

1. 启动后点「新建学生档案」，填写昵称和当前年级。
2. 点「记录新考试」，**先选考试所属年级**，再填考试名称、日期、类型。补录去年的考试请选去年的年级、日期。
3. 高一使用九科模板。高二、高三固定语文、数学、英语，首次选择其余三科。「3+1+2」要求物理/历史选一、化学/生物/政治/地理中选两科；「自由选三科」从六科中任选三科。高三首次设置可确认沿用高二组合。
4. 输入分数即标记为「已出分」，可修改满分和计分方式。缺考、待出分、本次未考均无分数；真实的 0 是有效成绩。此版本不自动计算赋分。
5. 保存后打开考试卡片查看详情及各科与最近一次可比考试的变化。录入页可存为草稿，返回时会提示保存；只有点保存并成功写库的数据可保证重启后仍在。
6. 「学生与选科」可新增学生、升级当前年级或按生效日期设置组合。已存成绩单保留自己的科目快照。相同学生、年级、生效日期只保留一份方案；补录时匹配不晚于考试日期的最近方案。

## 比较规则

总分仅在同学生、同年级、同类型、应考科目/满分/计分方式一致且两次均已出齐成绩时比较。不完整成绩显示出分进度和已知分之和。单科按同年级、同类型、同计分方式找日期更早的最近一次已出成绩；满分变化时只比较得分率（百分点）。同日考试不推断先后，草稿不参与比较。

## 开发及验证

需要 Flutter 3.47 或以上（Dart 3.13 或以上；本项目验证版本为 Flutter 3.50.1）。Android 需要 Android SDK 与匹配的 JDK；Windows 桌面构建需要 Visual Studio 的 C++ 桌面开发工具。项目根目录运行：

```sh
flutter pub get
flutter analyze
flutter test
flutter run -d windows
# 有安卓设备时
flutter devices
flutter run -d <device-id>
# 测试用安卓包，非正式签名发行版
flutter build apk --debug
```

## 实现与数据

- `lib/domain.dart`：年级模板、选科约束、按日期匹配方案、成绩状态与可比规则。
- `lib/store.dart`：Drift 管理的原生 SQLite 数据库；学生档案、带生效日的选科历史、考试及当场成绩快照。
- `lib/main.dart`：档案切换、考试列表、科目差值、详情及删除确认。
- `lib/plan_page.dart`、`lib/editor.dart`：选科与分步录入。
- `test/`：领域规则、真实 SQLite 重开持久化与 Flutter 界面流程测试。

数据库文件 `scorenote.sqlite` 位于平台应用支持目录。**本阶段未实现备份恢复或云同步**，卸载或清除应用数据可能丢失成绩。建议先用样例数据试用。跨年级手动比较、CSV 与备份恢复属于后续里程碑；账号、同步与冲突处理另行实现。

本机 PowerShell 可以用 `.\tools\score-note.ps1 check` 复验，或用 `.\tools\score-note.ps1 windows` 启动桌面版；脚本先查找 PATH 上的 Flutter，再查找本次安装的用户本地 SDK。桌面运行前请确保 C++ 工具链就绪。


若 Android 构建下载 Maven Central 依赖时返回 HTTP 403，可在 `flutter build apk --debug` 初次生成本机配置后使用仓库自带的临时 Gradle 镜像脚本。它只为本次运行增加 Google Cloud 的 Maven Central 镜像，不改全局 Gradle 配置：

```powershell
cd android
.\gradlew.bat -I ..\tools\maven-mirror.init.gradle :app:assembleDebug
```

## 0.2.0 · 排名与图表

- 总分及每科均支持班级、年级、联考三种排名；留空表示未知，非空须为正整数。旧版数据库打开后自动升级，旧记录排名保持空白。
- 「成绩概览」按学生、年级及科目组合筛选；已出齐的同口径考试组成总分折线，各科雷达图采用历次得分率的算术平均，显示样本场数。
- 点考试记录进入独立详情页：本场六轴/九轴雷达图、截至本场的可比总分趋势、可切换历史考试的两条单科对比折线，以及成绩、排名、差值明细。已出分的零分为真实数据，未知科目留空不连线。
- 图表支持展开查看准确数值；横向空间不足时可滚动折线图。

## 0.2.1 · 跨考试趋势
概览与考试详情的总分趋势默认按得分率（总分 ÷ 当场满分）绘图。同学生、年级、应考科目及计分口径相同的完整考试可跨类型、跨满分连线。切换到「原始总分」保留严格分组规则；概览明确区分所选范围场数与当前折线场数。

## 0.3.0 · 所有图表按排名绘制
当前版本以本节为准，替代 0.2.x 的得分率/原始总分图表。概览与详情默认展示年级名次，可切换班级、年级或联考。总分趋势使用总分排名，各科雷达和历史对比使用单科排名。纵轴顶端、雷达外圈均为第 1 名。平均排名仅纳入已填名次并显示样本场数，缺失名次不根据成绩推算。参评人数可能变化，图中是名次而非百分位。原有成绩和排名不需要迁移。
